# Politique de confidentialité

**Elm327 Live** respecte votre vie privée et ne collecte aucune donnée personnelle.

## Données collectées
L'application **ne communique jamais avec Internet**.  
Toutes les données sont traitées localement sur votre appareil via la connexion Bluetooth avec l’adaptateur ELM327.

L’application peut stocker localement certaines **valeurs de capteurs** pour permettre les fonctionnalités de **replay** ou d’historique.  
Ces données sont :
- stockées uniquement sur votre appareil,
- au format JSON,
- associées à un **timestamp**,
- **jamais transmises à des serveurs externes**.

## Utilisation des données
Les données locales sont utilisées **uniquement pour l’affichage des capteurs en direct, l’historique et le diagnostic** dans l’application.  
Aucune donnée n’est partagée, vendue ou utilisée à des fins publicitaires ou de suivi.

## Sécurité
Toutes les données restent sur votre appareil. Aucune connexion réseau n’est utilisée pour transmettre vos informations.

## Contact
Si vous avez des questions concernant cette politique de confidentialité ou le traitement des données, vous pouvez contacter le développeur via la page d’assistance de l’application.
